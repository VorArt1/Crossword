# Crossword
Этот учебный проект представляет собой консольное приложение на C#, которое позволяет пользователям создавать, редактировать и разгадывать кроссворды. Приложение реализует основные механики работы с сеткой кроссворда, проверкой слов и ведением счёта.
# Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/VorArt1/Crossword.git
   cd Crossword

2. Откройте решение в Visual Studio или любой другой IDE, поддерживающей .NET:
start Crossword.sln

3. Соберите проект:
dotnet build

# Использование
1. Запустите приложение:
dotnet run

2. Следуйте инструкциям в консоли:

 - Ввод слов для кроссворда
 - Управление сеткой
 - Проверка правильности заполнения

# Структура проекта

 1. Program.cs : Главный файл приложения, точка входа
 2. Crossword.csproj : Файл проекта .NET


# Требования
 - .NET SDK (версия 6.0 или выше)
 - Windows / Linux / macOS
